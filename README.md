# Árvore interativa

Versão independente e responsiva, sem cadastro ou login.

## Rodar localmente

Na pasta deste projeto, execute:

```powershell
node server.mjs
```

Depois abra <http://127.0.0.1:4173>.

Para publicar no GitHub Pages, envie pelo menos o `index.html` para um repositório e ative Pages em **Settings → Pages → Deploy from a branch**.
