# Adriana Botelho

Website institucional premium de Adriana Botelho, nutricionista. A experiência combina nutrição prática, culinária funcional, planejamento alimentar e uma direção editorial em verde profundo, ivory e terracota.

## Desenvolvimento

```powershell
npm install
npm run dev
```

Abra `http://localhost:3000`.

Para validar a versão de produção localmente:

```powershell
npm run build
npm run start
```

## Rotas

- `/` — Home institucional.
- `/sobre` — Storytelling da história e filosofia da Adriana.
- `/blog` — Busca, filtro e artigos demonstrativos.
- `/blog/[slug]` — Páginas individuais dos artigos.
- `/contato` — Agendamento provisório, formulário validado e FAQ.
- `/links` e `/links/` — Página de links legada preservada.

## Pendências de configuração

- O canal oficial de agendamento ainda precisa ser conectado.
- Formulários de contato e newsletter validam os campos, mas precisam de um serviço externo antes de enviar dados.
- Instagram e fotos editoriais adicionais aguardam URLs/assets confirmados.
- A Lista de Compras Inteligente está marcada como material em preparação; o e-book Bases Alimentares disponível pode ser baixado pela Home e pelo footer.
- Os três artigos do blog são demonstrativos e devem passar por revisão profissional antes da publicação final.

## Stack

Next.js App Router, React, TypeScript, Tailwind CSS, GSAP, ScrollTrigger, Lucide, React Hook Form e Zod.
